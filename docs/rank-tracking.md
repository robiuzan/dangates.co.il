# Rank tracking — dangates.co.il

Monthly Search Console snapshots, one section per month, generated by
`node scripts/audit/gsc-ingest.mjs <queries.csv> --month YYYY-MM --write` from the Performance →
Export CSV. Queries are bucketed into the site's keyword families (generic · service · location ·
symptom · component · brand) so movement is read per family, not per page.

## How to read a month

- **Impressions without clicks** in a family = the site is seen but not chosen: a title/description
  problem (`seo-metadata`) or a SERP feature the page doesn't earn (answer block, table).
- **Symptom / component impressions before a page exists** = demand the guides hub should capture
  next (`content-hub`, `docs/content-calendar.md`).
- **Location queries concentrated on 3–4 cities** = where the doorway retrofit (`new-city`) pays
  first; the rest of the 18 can wait.
- **Position 8–15 on a generic head term** = the page is indexed and competing; depth and links move
  it. Position > 30 = the page is not really in the race; fix the page, not the links.
